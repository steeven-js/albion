# 🏰 Donjons solo (Solo Dungeons)

Tous les types de donjons faisables en solo.

---

## Donjons aléatoires (Random Dungeons — RDs)

Spawn aléatoire dans toutes les zones du monde. Symbole d'entrée sur la minimap.

### Caractéristiques
- Durée : ~15-20 min par run
- Loot : coffres à la fin + mobs
- Fame : correct pour monter la spé arme
- Risque : selon la zone (jaune = safe, rouge = gank possible)

### Stratégie
1. Rentrer, **clear** tous les mobs en spam Q+W
2. Focus les **mini-boss** (loot garanti)
3. **Blood Bandit** sur packs pour heal
4. Coffre final = silver + loot

### Où en trouver
- Sur la **map locale** (touche M), icône de porte
- **Zones jaunes T5-T6** = safe et rentables pour débuter
- **Zones rouges T6+** = plus de loot mais risque de gank

---

## Donjons Corrompus (Corrupted Dungeons — CDs) ⭐

Accessibles depuis **n'importe quelle ville**. Instanciés.

### 3 difficultés

| Niveau | Nom FR (EN) | PvP | Perte stuff | Recommandé |
|--------|-------------|-----|-------------|------------|
| 1 | Chasseur (Hunter) | KO only | Non | **Pour toi** |
| 2 | Traqueur (Stalker) | Full loot | Oui | Plus tard |
| 3 | Tueur (Slayer) | Full loot | Oui | Avancé |

### Mécanique
- Tuer les mobs → monter l'**Infamie**
- À certain seuil → le **boss final** apparaît
- Coffres éparpillés dans le donjon = silver + tomes
- **Invasion possible** (en Stalker/Slayer) : un autre joueur peut envahir ton instance

### Build recommandé (Hunter)
Même que le build PvE principal :
- Hache de Guerre + Torche
- Veste de Mercenaire
- Casque de Gardien (pour tank le boss)

### Loot type (Hunter)
- Silver direct (coffres + drops)
- **Tomes de découverte (Tomes of Insight)** : +fame libre
- Runes/âmes/reliques
- Parfois : artefacts rares

---

## Donjons d'Expédition (Expeditions)

Mini-donjons scriptés depuis le Maître d'Expédition en ville.

### Caractéristiques
- Parfait **débutant** ou **petit farm quotidien**
- Silver + fame modérés
- 100% safe (pas de PvP)
- Durée : 10-20 min

**Moins rentable que les Mists**, mais safe à 100%. Idéal pour se détendre.

---

## Donjons de groupe en solo ?

### Donjons bleus / verts (Blue/Green Group Dungeons)
- Faisables **en solo si bien gearé**
- Loot T5+ intéressant
- Plus lent qu'un donjon aléatoire mais meilleur loot

### Donjons jaunes / oranges / rouges
- **Pas en solo** → trop de HP sur les boss, tu n'y arriveras pas
