# 🎒 Sets de rechange (Loadouts)

Liste des sets à garder en banque pour pouvoir se ré-équiper rapidement.

## Règle d'or

**Toujours avoir minimum 3 sets complets de rechange** pour ton activité principale.
Chaque set inclut : arme + off-hand + casque + torse + bottes + cape + bouffe + potions.

## Où stocker

- **Banque en ville** : sets principaux, monture de transport
- **Île personnelle (Personal Island)** : stock de ressources, runes, objets précieux
- **Coffre d'hideout de guilde** : plus tard, si tu rejoins une guilde

---

## Assurance (Insurance / Loadouts)

Via le menu **Équipement → Loadouts** en ville :
1. Créer un loadout avec ton set actuel
2. Il sera **automatiquement racheté** depuis ta banque si tu meurs
3. Très pratique pour ne pas perdre de temps à re-équiper

**À configurer dès que possible.**
